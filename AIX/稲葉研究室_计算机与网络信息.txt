[* GPUサーバ使用方法]
	電通大VPN or 学内からのアクセスが必要です
 	ゼミ室からはローカルIPアドレスを使用して各サーバにSSH接続できます．
 	電通大VPNの場合
 		ELIZAグループ：130.153.158.3にSSH接続し，そこからさらにSSHで他のサーバに接続
 		SHRDLUグループ：130.153.158.3，ポート番号12456でSSH接続し，そこからSSHで他のサーバに接続
	ELIZAグループの場合は自分のユーザ名のフォルダを「/export/users/」以下に，SHRDLUグループの場合は「/shrdlu/users」以下に作成し，プログラムなどのデータはそこに保存してください
		ホームフォルダは容量が小さいです
	ELIZAグループの場合
 	Windowsのエクスプローラに「\\130.153.158.3」と入れると，そのフォルダにWindows上からアクセスできます
 	macOSの場合，Finderの右上の「移動」＞「サーバに接続」を選択し，smb://130.153.158.3 を入力すればOK
 	/export/share/dataに研究用の共用データがあります
 SHRDLUグループの場合
 	現状研究室内限定でWindowsエクスプローラに「\\192.168.10.60」と入れるとファイルサーバにアクセスできます

[* 空いているGPUの確認方法]
	各サーバは /export/public/nvidia-smi/ 以下に1分おきにnvidia-smiの結果を出力するようにcronで設定しています
	出力ファイルの中身を一括表示するシェルスクリプトを用意したので，以下を実行するとGPUの状況が確認できます
	 $ sh /export/public/nvidia-smi/show.sh
	エイリアスを設定しておくと楽です
		例：ホームディレクトリの「.bashrc」の末尾に以下を追記すると，gpushowコマンドでシェルスクリプトが実行できる
			alias gpushow="sh /export/public/nvidia-smi/show.sh"

[* パスワード無しでの接続（公開鍵認証の設定）]
	公開鍵認証を設定しておくとVSCodeの接続時にパスワードを聞かれなくなる
 	手順
 		接続元のPCで鍵を作成
 			Windows Terminalの場合
 				$ ssh-keygen -t ed25519
 					プロンプトはすべて何も入力せずエンターを連打
 		.sshディレクトリ内に作成されたid_ed25519.pubをGPUサーバのホームディレクトリの./sshディレクトリに保存
 		以降はGPUサーバ上でコマンド実行
 			$ cd
 				ホームディレクトリへ移動
 			$ chmod 700 .ssh
 			$ cd .ssh
 			$ cat id_ed25519.pub >> authorized_keys
 			$ chmod 600 authorized_keys
 		接続元PCのターミナルから接続できるかを確認
 			$ ssh -i .ssh/id_ed25519 (ユーザ名)@(サーバのIPアドレス)
 			パスワードを聞かれずにログインできればOK．聞かれた場合は設定が間違っている
 		[VSCode]の設定
 			SSHのconfigファイルに以下例のように記述
  			code:config
  			 Host siri
        HostName 192.168.10.28
        User (ユーザ名)
        PasswordAuthentication no
        IdentityFile (id_ed25519ファイルのフルパス．例：C:\Users\inaba\.ssh\id_ed25519)
        IdentitiesOnly yes

[* 多段SSH]
	VPNを介する場合など，VSCodeでGPUサーバに直接接続できない環境の場合は[多段SSH接続 https://qiita.com/ktokey/items/70882ecca1a21bb40b53]でelizaを踏み台にGPUサーバに接続するように設定する
		code:設定例
		 Host eliza
           HostName 130.153.158.3
           User (ユーザ名)
   
   Host alexa
           HostName 192.168.10.33	
           User (ユーザ名)
           ProxyCommand  ssh -W %h:%p eliza
           
   Host pepper
           HostName 192.168.10.35	
           User (ユーザ名)
           ProxyCommand  ssh -W %h:%p eliza


[* アカウントの作成]
	管理者(稲葉)に依頼してください
	最初はユーザ名とパスワードは同一になっているので，以下のコマンドで[* 必ず]両方のパスワードを変更してください
		ELIZAグループの場合はeliza上で，SHRDLUグループの場合がshrdlu上で実行すること
		$ passwd
			ログインパスワードの変更
		$ smbpasswd
			sambaのパスワードの変更

[* 注意]
	ファイルサーバでのプログラムの実行は避けてください
	VSCodeでファイルサーバに接続すると，VSCodeの設定ファイルやhuggingfaceなどのキャッシュファイルで容量を圧迫し，動作が不安定になる可能性があるため，VSCodeで接続するのはGPUサーバだけにしてください．
		GPUサーバに直接接続できない環境の場合は[多段SSH接続 https://qiita.com/ktokey/items/70882ecca1a21bb40b53]でelizaを踏み台にGPUサーバに接続するように設定すること
	GPUサーバにログインしたらtopコマンドとnvidia-smiコマンドで使用状況を確認し，余裕があることを確認しましょう
